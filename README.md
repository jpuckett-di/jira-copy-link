# Jira Copy Link

The script will add a "copy" button to the top-left corner of Jira issue pages.
Clicking the button will copy the issue key and title as an HTML link to your clipboard, ready to paste into documents.

## Installation

1. Install the [Violentmonkey](https://violentmonkey.github.io/) browser extension
2. Click [here](https://raw.githubusercontent.com/jpuckett-di/jira-copy-link/refs/heads/main/main.user.js) to install the script
